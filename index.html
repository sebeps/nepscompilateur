    Restaurer une liste copiée
    Comment créer le lien dans Nextcloud ?
    1. Dans Nextcloud, créez un dossier (par exemple « 6A – endurance »).
    2. Cliquez sur Partager, puis sur le + de « Partager le lien ».
    3. Choisissez « Dépôt de fichiers » : les élèves déposent sans voir ni supprimer. Jamais « Lecture seule » ni « Peut modifier ». Le libellé peut varier selon votre version.
    4. Copiez le lien et collez-le dans un emplacement ci-dessus, avec le nom de votre choix.
    5. Cliquez sur « Tester », idéalement dans une fenêtre de navigation privée : une zone de dépôt, c'est bon ; une liste de fichiers, le partage est mal réglé.
    6. Montrez le « QR plein écran » à la classe. Votre tablette l'affiche sans internet, mais les élèves en ont besoin pour déposer.
    7. Pour récupérer les fichiers : choisissez-les dans Nextcloud avec le sélecteur de fichiers de cette tablette (application Nextcloud installée), puis importez-les dans le volet 1. Les doublons sont ignorés.

    Le lien ne contient aucun mot de passe : toute personne qui le possède peut y déposer. S'il circule trop, supprimez le partage dans Nextcloud et créez-en un autre. Vos liens sont conservés sur cette tablette ; installez l'application sur l'écran d'accueil et utilisez « Copier la liste de mes liens » comme secours. Effacer les données du navigateur les supprime.

    Chaque élève ouvre son application et touche « Mon QR code ». Scannez son écran avec la caméra de cette tablette, un élève après l'autre : aucun internet n'est nécessaire, ni pour vous ni pour eux.

    Tous les élèves doivent avoir les mêmes en-têtes : un élève dont les en-têtes diffèrent est refusé. Un élève déjà scanné est reconnu et ignoré. Sur Android avec Chrome, la lecture est intégrée ; sur iPad, elle demande le fichier jsQR.js dans le dossier vendor (voir le mode d'emploi).

    Fusionner les lignes d'un élève

    Étape 2 — Lignes de l'élève, puis formule de chaque colonne

    Sous chaque colonne, choisissez une formule dans la liste. Pour aller plus loin, choisissez « ✎ Formule libre… » et écrivez-la comme dans un tableur : =SOMME(D1:D3), =(MOYENNE(D)+MOYENNE(E))/2, =D1-D2 (D1 = colonne D, ligne n°1 de l'élève). La ligne « Résultat » est la ligne unique de l'élève.

    Les colonnes Nom et Classe ne sont pas modifiées.
